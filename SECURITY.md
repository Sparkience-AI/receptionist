# Security

To report a vulnerability, open the repository’s [Security tab](https://github.com/Sparkience-AI/receptionist/security) and use **Report a vulnerability** if available. If private reporting is unavailable, use the maintainer’s private contact channel. Keep vulnerability details out of public issues and pull requests.

Include the affected commit or version, what can go wrong, and a minimal reproduction using synthetic data. Remove API keys, private prompts, and identifying information from attachments.

Revoke and replace any provider key that was exposed. Use a sidebar password field or an environment variable for provider credentials.
